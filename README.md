# talking-back-site

Public pages for the Talking Back app, served by GitHub Pages at https://enea-13.github.io/talking-back-site/:

- `index.md`: the Support page (App Store "Support URL")
- `privacy.md`: the privacy policy (App Store and Google Play "Privacy policy URL")

`privacy.md` is a copy of `docs/privacy.md` in the app's own repository, which the app also shows on its Privacy screen. Change it there first, then copy it here.
